# MS-001 Stage 0 model geometries (B1) and validation configurations (C7)

Status: Stage 0 definition under scope option B (declared-deviation study). Every file here is `[AGENT]`: a
geometric construction proposed by this project, not a measurement or a result.

- **Built by geometry only.** The files were built from declared rules: lattice points, a dimer and cap
  construction, rigid rotations and rigid translations. Nothing was relaxed or optimized. No calculator was attached,
  and no energy, force or gradient was evaluated.
- **Nothing electronic was computed.** Bond order, bond formation or cleavage, electronic state, spin state and
  stability were not computed.
- **Not the benchmark geometry.** These files are not a model of the benchmark's geometry. They have not been
  compared with the benchmark authors' coordinates, which this project has not obtained `[GAP]`.
- **Parity unknown.** Parity with the benchmark is unknown for every item.

The generator measures every distance and angle it reports on the coordinates it has just written and read back. It
then asserts each against its declared value within declared tolerances: 1 × 10⁻⁶ Å for distances and 1 × 10⁻⁴°
for angles. This establishes only the internal consistency of a geometric construction. It is not physical
validation and says nothing about chemistry, bonding or stability.

## Format

The files use extended XYZ, as written by ASE 3.29.0.

- **Coordinates.** Coordinates are in ångström (`units=Angstrom` in each header) and are non-periodic
  (`pbc="F F F"`, no cell).
- **Columns.** Each atom line carries `species`, `pos`, a stable identifier `atom_id` and a `role`:
  - `M1-Si-dimer`, `M1-Si-3c-site` or `M1-Si-sub` for Si
  - `M1-H-dimer` or `M1-H-cap` for H
  - `M2-tool` or `P2-molecule` otherwise
- **M1 identifiers.** M1 Si atoms are named `S-L<layer>-<x>-<y>`, where layer 1 is the dimer layer and x and y are
  integer lattice coordinates in half surface spacings. A hydrogen is named after its Si, as `<Si id>-H<k>`.
- **Header keys.** Each header records `evidence_class=AGENT` and the complete `not_computed` statement. It also
  records `charge_multiplicity` ("not assigned here; no electronic-state claim; assignment deferred to B2"), the
  generator name and digest, and the software versions.
- **C7 keys.** The C7 files add `c7_role`, `construction_rule` and, for V1 to V3, `filename_note`. The note states
  that "intact" and "broken" in two file names are nominal C7 names that denote the geometry recipe only, not bond
  states.

model geometry, cluster or slab size, termination and placement are not available (`[GAP]`).
